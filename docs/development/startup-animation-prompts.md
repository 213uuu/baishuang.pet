# 白霜 · 开场动画提示词（紫蛋破壳）

用途：给白霜做一段"开场／启动动画"——紫色蛋壳渐渐裂开、晃动，她破壳爬出、站好。
配合 `动作动画提示词.md`（单动作）和 `动作提示词.md`（状态转换）一起用。

## 0. 用法

1. 总时长 **8~10 秒**，24fps 导出；导出后我按每 2 帧取 1 帧抽成 12fps。
2. **分镜生成**：整段一次生成容易崩（蛋形变、出现第二个人、镜头乱跑），
   建议按下面 6 个镜头分别生成，用上一镜的末帧当下一镜的首帧，串起来。
3. 相机**全程固定**、背景**纯色**、蛋（和她）在画面中央偏下，地面基线不动。
4. 前面 4 个镜头**不要让她出现**——先只有蛋。这是最容易崩的地方。

## 1. 通用块（每个镜头都加上）

```
【角色（出场后）】Q版约2.5头身的龙娘少女：白色长直发（发梢淡紫/浅粉）、紫色眼瞳、
白色长裙配黑色胸衣、黑色长袜、头顶一对深紫色小角、紫红色蝴蝶结发饰、
身后一条紫色鳞纹龙尾（没有翅膀）。冷脸傲娇，表情细腻。

【蛋】一颗约到她腰高的紫色龙蛋：表面是深紫到紫红的鳞纹，有微微的哑光质感，
蛋壳缝隙里可以透出紫白色的光。

【镜头】固定机位，正面平视，主体居中偏下；不推拉、不旋转、不抖动、不变焦。
【背景】纯绿色 #00FF00 平坦背景，无阴影、无杂物、无地面纹理。
【风格】日系赛璐璐上色，清晰描边，无运动模糊，无景深虚化。
【物理】蛋壳碎片要有重量感，落地后弹一下再停；整体动作用缓入缓出，不要匀速直线。
```

## 2. 分镜提示词

### 镜头 1 · 静止的蛋（0~1.5s）
```
【动作】一颗紫色龙蛋立在画面中央，完全静止，表面鳞纹清晰；只有极轻微的反光变化。
不要出现人物，不要有裂缝。
```

### 镜头 2 · 第一道裂缝（1.5~3s）
```
【动作】蛋开始极轻微地左右晃动（幅度约蛋宽的 3%），
顶部慢慢出现第一道细裂缝，并缓缓向下延伸；有很少的碎屑掉落。
仍然不要出现人物。
```

### 镜头 3 · 晃动加剧、裂缝变多（3~4.5s）
```
【动作】晃动幅度加大到蛋宽的 8% 左右，节奏变快；
裂缝从一道变成多道，缝里透出紫白色的光；蛋壳表面开始有小碎片被顶起来。
```

### 镜头 4 · 探出头（4.5~6s）
```
【动作】蛋壳从顶部裂开一个缺口，先冒出她的白发和一对深紫色小角，
随后额头与眼睛露出；她左右看了一眼，再顶开更多碎片。
裂缝处的光要慢慢减弱，不要一直亮着。
```

### 镜头 5 · 爬出来（6~8s）
```
【动作】她用手撑住蛋壳边缘，一条腿先迈出来，另一条腿跟上，
整个人从蛋里爬出、落到地面上；过程中带出几片蛋壳碎片。
落地后膝盖微弯缓冲一下（有重量感）。
```

### 镜头 6 · 站好、抖壳、看向镜头（8~10s）
```
【动作】她站直身体，轻轻抖一下肩膀和头发，把身上的碎壳抖落；
顺手拍两下裙子，最后抬眼看向镜头，嘴角压着一点小得意（傲娇地"哼"一声的那种神态）。
结尾保持站立姿态 0.5 秒，方便我做首尾帧对齐。
```

## 3. 单条版（工具只吃一条提示词时用）

```
【镜头】固定机位正面平视，主体居中偏下，比例不变。
【背景】纯绿色 #00FF00 平坦背景，无阴影无杂物。
【过程】一颗紫色鳞纹龙蛋立在画面中央：先完全静止，接着开始轻微晃动，
顶部出现第一道裂缝并向下延伸；晃动逐渐加大、裂缝变多，缝里透出紫白色的光；
随后蛋壳从顶部裂开，先露出白发与一对深紫色小角，再露出脸蛋；
一个Q版龙娘少女撑住壳边爬出来落到地上，站直、抖掉身上的碎壳、拍两下裙子，

【风格】日系赛璐璐上色，清晰描边，无运动模糊；动作缓入缓出，蛋壳碎片有重量感。
```

## 5. 参数建议

| 项 | 建议 |
| --- | --- |
| 总时长 | 8~10 秒（分镜每镜 1.5~2 秒） |
| 帧率 | 24fps 导出，抽帧时每 2 帧取 1 帧 |
| 分辨率 | 1:1，≥1024×1024（越高越好抽帧） |
| 运动强度 | 中低；镜头运动选项**关闭** |
| 生成方式 | 分镜 + 首尾帧串联（上一镜末帧 → 下一镜首帧） |

## 6. 我这边怎么接

1. 抠绿底 → 逐帧带 alpha；
2. 与既有帧做整帧互相关对齐（判据：残差降幅 ≥45% 且位移 ≤3 像素才平移）；
3. 按身高归一化到桌宠格子（脚底基线固定，预留蛋壳碎片的位置）；
4. 作为**启动动画**写进 `frames/boot/`，程序启动时先播一遍再进待机；
5. 验收项：蛋形是否稳定、人物是否提前出现、基线是否对齐、末帧是否是站姿。

## 7. 最容易崩的三处

| 症状 | 对策 |
| --- | --- |
| 人物在裂缝阶段就出现 | 前 4 镜的提示词里明确"不要出现人物"，并在负面里写 `character appears too early` |
| 蛋壳凭空消失／变形 | 首尾帧都带上蛋壳的位置；蛋的尺寸、位置、颜色三个镜头之间保持一致 |
| 破壳后动作糊成一团 | 提高分辨率、降低运动强度；把"爬出"和"站好"拆成两镜 |
