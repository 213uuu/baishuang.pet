# 白霜 · 动作动画提示词（视频／动画生成用）

配合 `动作提示词.md` 使用：那份讲**状态之间的转换**，这份讲**每个动作本身的动画**。

## 0. 用法（照做能省一大半返工）

1. **一定用首尾帧**：首帧喂"动作开始"那张桌宠帧，末帧喂"动作结束"那张。
   现成文件都在 `frames/<状态>/`，例如打招呼用 `frames/waving/00.png` → `frames/waving/04.png`。
   首尾帧把角色钉死，模型只负责中间的动，一致性比纯文生视频高一个数量级。
2. **时长 1.5~2.5 秒**，24fps；导出后我按每 2 帧取 1 帧抽成 12fps 接进桌宠。
3. **相机固定、纯色背景、全身入画、脚底基线不动**——这三条不写，后期对齐救不回来。
4. 一次只生一个动作，别把多个动作塞进一条提示词。

## 1. 通用块（中文，任何一条动作提示词前面都加上）

```
【角色】Q版约2.5头身的龙娘少女：白色长直发（发梢淡紫）、紫色眼瞳、白色长裙配黑色胸衣、
黑色长袜、头顶一对深紫色小角、紫红色蝴蝶结发饰、身后一条紫色鳞纹龙尾（没有翅膀）。
冷脸傲娇，表情细腻，不做夸张鬼脸。

【镜头】固定机位，正前方略偏左的三分之四视角，全身入画，人物居中，
脚底基线全程固定不动，人物比例不变；不推拉、不旋转、不抖动。

【背景】纯绿色 #00FF00 平坦背景，无阴影、无杂物。

【风格】日系赛璐璐上色，清晰描边，无运动模糊，无景深虚化。

【通用运动要求】动作连贯、缓入缓出；视线先行、头部跟随、躯干最后；
头发与龙尾的摆动滞后身体 1~2 帧；中途不跳变、不闪断、四肢数量与结构全程正确。
```

## 2. 逐动作提示词（接在通用块后面）

### ① 启动／打招呼 · 2 秒
```
【动作】从自然站姿开始：右手从身侧抬起、抬到胸前高度轻轻挥两下再放下；
视线先看向镜头，随后轻颔首；发梢与尾巴摆动比手慢半拍。
```

### ② 进入工作 · 2 秒
```
【动作】视线先垂下，双臂收拢到腰侧掐住（双手掐腰），肩微微耸起、下巴略低；
眉毛压低、嘴角下撇，一副"嫌弃又懒得说"的样子；最后尾巴梢轻甩一次。
```

### ③ 工作完成 · 2 秒
```
【动作】双手从腰上放下；胸口先挺起、下巴再后抬（昂首），眼睛半闭、嘴角上扬，
露出"哼，弄完了"的得意；尾巴向上挑起。
```

### ④ 干活时被打扰（烦躁→心虚）· 2.5 秒
```
【动作】前半段：一只脚快速抬起落下两次（跺脚），眉头紧皱、嘴张开，一副不耐烦；
后半段：迅速转变为肩一缩、头低下去、脸颊泛红、眼神向左下躲闪的心虚神态。
两段之间要连贯过渡，不要硬切。
```

### ⑤ 空闲时被点（抬头看）· 1.5 秒
```
【动作】眼球先转向镜头，头部随后轻轻抬起看向镜头，身体几乎不动；
最后轻轻歪一下头，像在问"嗯？有事？"。
```

### ⑥ 害羞 · 2 秒
```
【动作】视线先向下躲开，随后头低下去、双手在身前轻轻攥紧、脸颊泛红加深、肩微缩；
呼吸起伏变浅，整段动作幅度小、速度慢。
```

### ⑦ 连点炸毛 · 2.5 秒
```
【动作】抱胸、瞪眼、张嘴喊出（气急败坏）；身体小幅前后晃动两次，
发丝与尾巴随动甩开，末尾把头别向一侧，不再看镜头。
```

### ⑧ 偷看被发现 · 2 秒
```
【动作】头快速转向镜头（只用 1~2 帧完成转头），随即立刻转回并低下去，
同时脸红、眼神躲闪——"偷看被抓包"的完整反应。
```

### ⑨ 收工告别 · 2 秒
```
【动作】视线垂下、肩放松、头低下去，双手在身前轻攥；半步侧身但不要背对镜头，
尾巴收拢。整段要收敛、安静。
```

### ⑩ 待机循环 · 2 秒（可无缝循环）
```
【动作】自然站姿的呼吸起伏：身体上下浮动约 1~2 像素的幅度、周期 2 秒；
发梢与尾巴轻微跟随，视线保持向前。首帧与末帧必须完全一致，方便无缝循环。
```

## 3. 参数建议

| 项 | 建议 |
| --- | --- |
| 时长 | 单动作 1.5~2.5 秒（待机循环 2 秒） |
| 帧率 | 24fps 导出，抽帧时每 2 帧取 1 帧 |
| 运动强度 | 中低（高了会糊、会变形） |
| 分辨率 | 1:1，≥768×768（越高越好抽帧） |
| 采样 | 固定 seed 可复现；一条提示词只做一件事 |

## 4. 我拿到之后怎么接

1. 抠绿底 → 带 alpha 的帧；
2. 与现成立绘/帧做**整帧互相关对齐**（判据：残差降幅 ≥45% 且位移 ≤3 像素才平移）；
3. 按身高归一化到桌宠格子（脚底基线固定，当前 192×208；要高分辨率就乘统一倍数）；
4. 写进 `frames/<状态>/`，需要的话再补 `trans-<旧>-<新>/` 过渡帧；
5. 验收：尺寸、帧数、末帧是否是干净姿势、基线是否对齐——这四样都会过一遍再交付。

## 5. 常见崩坏与对策

| 症状 | 对策 |
| --- | --- |
| 长出翅膀／恶魔角 | 通用块里正面点名"没有翅膀"、负面里写 `wings, demon horns` |
| 白裙变黑裙 | 正面写 `pure white dress`，负面写 `black dress, black skirt` |
| 镜头缩放／人物漂移 | 明确"固定机位、基线不动、比例不变"；仍漂就用首尾帧插值 |
| 动作糊成一团 | 降低运动强度、缩短时长、提高分辨率 |
| 表情在中段丢 | 首尾帧里带上表情，提示词里写明"整段保持该表情" |
